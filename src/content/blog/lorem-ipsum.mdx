## Code

Inline code looks like `npm run build`, and fenced blocks get syntax highlighting:

```ts title="greet.ts" {1,3}
export function greet(name: string): string {
  const message = `Hello, ${name}!`
  return message
}
```

Line ranges in the meta string highlight specific lines, like `{2}` here:

```bash {2}
npm run dev
npm run build
```
